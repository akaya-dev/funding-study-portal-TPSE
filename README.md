To run the code:

1. Install JDK 25
2. install the jar at: https://www.mediafire.com/file/70aglx6094kbohe/student-funding-portal-0.0.1-SNAPSHOT.jar/file
3. open the download location via cmd and run this command: java -jar student-funding-portal-0.0.1-SNAPSHOT.jar
4. go to localhost:8080/form
5. done
